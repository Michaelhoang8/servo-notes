Event positions are zero-based sample indices: stepAt raises the target, returnAt changes it again, and disturbanceAt adds a sustained input disturbance. Duration is dt × steps. A missing or invalid field is rejected.

Equations & interpretation

The plant is dy/dt = (−y + gain × (applied command + disturbance)) / tau. It uses the exact zero-order-hold update over each sample interval. Commands are clipped before an integer-sample delay queue; the initial queue contains clipped zero commands.

The derivative acts on a low-pass-filtered measurement difference, avoiding a setpoint derivative kick. Conditional integration rejects outward integral accumulation during saturation. Back-calculation feeds the clipped-minus-unclipped command difference into the next integral state.

All variants receive the same seeded uniform measurement-noise sequence. These are explicit discrete controller conventions, not a claim of equivalence to a particular industrial PID implementation. No auto-tuning, stability guarantee, or hardware connection is provided.

Controller magnitudes above 1e9 stop that run with an explicit partial result. Results depend on sampling, delay, model assumptions, and gains. Use this as a numerical experiment, not a controller deployment tool.
